# FORM-AI 💪

**FORM-AI** is a fun, interactive workout app that uses real-time pose detection to track reps, give feedback, and improve your form — all with animated characters and game-like cutscenes.

### 🛠 Built With
- Python + Pygame
- OpenCV + MediaPipe
- PHP + MySQL (for leaderboard)
- HTML/CSS + JavaScript (for the website)

### 🚀 Features
- Real-time rep tracking
- Good/bad form feedback with sound
- Animated character intros
- Online leaderboard system
